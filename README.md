# workbench

AI に作らせたいもののアイデアハブ。ここには「何を・なぜ作るか」だけを置き、コードは置かない。
実装は別リポジトリで行い、issue からリンクする。

## 流れ

1つの issue がラベルを付け替えながら育っていく。

| ラベル | 状態 |
|---|---|
| `idea` | 思いつき。タイトルと1〜2行でよい |
| `spec` | AI と壁打ちして仕様化中 |
| `ready` | 仕様が固まり、AI に丸投げできる。情報が足りているかは AI が判定して上げる |
| `building` | 実装リポジトリ作成済み、作業中 |
| `shipped` / `dropped` | 完成 / 見送り（理由を1行残して close） |

## トリアージ

`triage` ラベルを付けると、AI が本文の末尾に「決まったこと・未決のこと・完了条件の叩き台・類似の issue」を書き、終わるとラベルを外す（`.github/workflows/triage.yml`）。

- アイデア用テンプレートで issue を作ると最初から付いているので、作成直後に1回走る
- 作成後の補足・変更・質問への回答は、本文ではなくコメントに書く
- コメントを反映させたい時は `triage` ラベルを付け直す。本文のトリアージ結果が最新に差し替わる

`ready` になっても自動では作り始めない。作るのは「#NN を作って」と頼んだ時。close と `shipped` / `dropped` は自分で付ける。

AI 向けの運用ルールは [CLAUDE.md](CLAUDE.md) を参照。
